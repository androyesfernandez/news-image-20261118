A deterministic, standard-library-only Python program that draws a one-page newspaper poster summing up the world news of Wednesday 18 November 2026, and writes it to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Nine cross-verified stories of that day — Iran's strikes on Gulf bases after the U.S. Qeshm hit, Xi and Putin meeting in Shenzhen, the Zaporizhia aid-centre toll rising to 40, Congo Ebola cases passing 11,000, Voyager 1 reaching one light-day from Earth, Peltola's Alaska win, the U.S. losing measles-free status, Nvidia's $130B quarter, and the COP31 fight over climate-aid cash — rendered pixel by pixel with an embedded bitmap font. No network, no clock, no randomness: every run produces byte-identical output (1024×1024 PNG, ~20 KB).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
